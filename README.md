# Guia de Organização e Nomenclatura de Imagens - Muay Thai na Quebrada

Este documento instrui desenvolvedores, designers e colaboradores sobre como estruturar, nomear e organizar os arquivos de mídia para o site **Muay Thai na Quebrada**. A padronização é fundamental para garantir o funcionamento correto dos caminhos (paths) no HTML e otimizar a performance de carregamento.

---

## 📂 Estrutura de Pastas

Todas as imagens do projeto devem obrigatoriamente residir dentro da pasta `images`, localizada na raiz do repositório.

```text
muay-thai-na-quebrada/
├── index.html          # Arquivo principal do site (Monolítico)
├── README.md           # Este arquivo de documentação
└── images/             # DIRETÓRIO OBRIGATÓRIO PARA AS FOTOS
    ├── 1.jpg           # Foto do Hero Banner
    ├── 2.jpg           # Fotos da seção 4 Anos (Torneio)
    ├── ...
    ├── 22.jpg          # Fotos da seção Nossa História
    ├── ...
    └── 32.jpg          # Fotos da seção Conquistas
